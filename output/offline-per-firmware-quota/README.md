# 按固件独立限制烧录次数（2026-10-28）

每份目标固件单独保存剩余次数。切换固件自动加载它自己的额度；上位机重新导入同名固件，按当前勾选和次数重设该固件，其他固件余额不变。

## 升级与使用

1. 将本包 DAPlink.bin 通过现有文件传输功能上传到设备 /update/DAPlink.bin，重新上电更新烧录器应用。DAPlink.hex 为从 0x0800C000 开始的应用镜像。
2. 使用本包 tools/run.bat 启动配套上位机；新版上位机与新版设备固件需配套。旧设备会在导入前得到升级提示，不会误改旧全局次数。
3. 在“固件烧录次数”中勾选限制并填写 0～999 后导入。重新导入设100即恢复100；取消勾选后导入，该固件改为不限。“保存当前固件”和读取按钮针对设备当前选择的固件。
4. 手动模式切换固件会恢复其余额。没有额度记录的旧固件为不限；有限次数保留余额，0次禁止烧录。
5. tools 可在仓库中复用现有 Python3.12 环境；独立使用需建立 tools/.venv 并安装 intelhex pyusb PyQt5 libusb-package。algorithms 为原配套算法，设备已有同名算法无需重传。

## 兼容与保存规则

- 旧版只保存一份全局额度，没有每个文件的历史次数。升级时把旧额度关联到最后保存的固件；其余没有记录的旧固件按不限处理。无可恢复的旧固件名时，旧全局额度无法推断归属，应重新导入需要限制的固件。
- 成功烧录扣一次，普通失败退回一次；烧录中断电保留已预扣的一次。重新上电保留芯片、固件选择及各固件余额。
- 固件身份按正常设备完整文件名区分（ASCII大小写不敏感）。不同文件名分别计数；通过接口访问文件时使用完整长文件名，不使用DOS短文件名别名。
- 当前余额写内部双页日志；切换时把非当前余额写 0:/system/burnquota.dat，账本提交长度和CRC保存在内部日志中。不要删除或改写此系统文件；已提交账本缺失/损坏会拒绝切换烧录，不会恢复无限次数。次数账本占用少量SPI文件系统空间，空间不足时保留当前额度并报错。
- 内部选择日志为0x0801F000～0x0801F7FF，次数日志为0x0801F800～0x0801FFFF；本应用镜像不覆盖它们。仅更新应用即可，Bootloader和标准FLM版未修改。
