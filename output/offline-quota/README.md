# 带次数限制的中文离线烧录器

日期：2026-10-23

## 设置次数

1. 安装本目录的新应用固件，用新上位机 `tools/run.bat` 连接设备。设备应处于文件传输页或模式选择页；长按中键可从烧录页返回。
2. 勾选“启用次数限制”，输入 100，点击“保存到设备”，等待显示“剩余次数：100次”。建议在“导入程序”之前设置，因为导入完成会自动断开 USB。
3. 设备屏幕显示“剩余次数:100次”。每次成功烧录扣一次，依次显示 099、098……000。
4. 次数为 000 时，自动或手动再次烧录都会提示“烧录失败”“剩余次数不足”，并阻止烧录。
5. 重新连接后，点击“读取剩余次数”查询。需要新额度时，输入新次数并保存；取消勾选后保存，恢复不限次数。

次数是整台设备的全局额度，范围 0–999，新设备默认不限。重新导入程序、切换算法、重启和普通应用升级均不重置额度。
正常检测到的烧录失败不扣次数。设备在操作目标芯片前先保存一次扣减，失败后退回；烧录过程中断电会消耗此次次数，避免断电后重复获得额度。记录写入失败或损坏会阻止烧录，提示“次数记录异常”，可在上位机重新设置并保存。

## 固件与升级

- `DAPlink.bin`：应用升级文件，通过上位机上传到 `/update/DAPlink.bin`，随后断电重启。
- `DAPlink.hex`：应用镜像，起始地址 0x0800C000。
- `Bootloader-Quota.hex/.bin`：新版中文启动程序，限制应用升级大小，保护次数记录。外部工具写入地址 0x08000000；不要上传到应用更新目录。
- `DAPlink-Quota-full.hex`：启动程序和应用的合并镜像，供外部烧录工具整机安装。推荐首次使用此版本时一并更新启动程序。
- `tools/`：新上位机源文件、芯片配置及启动脚本；工作区已有经过验证的 Python 3.12 环境。
- `*-320x240.png`、`ui-preview.png`、`quota-host-preview.png`：实际字库/坐标渲染的屏幕预览及上位机预览。
- `manifest.json`、`verification.json`、`quota-*-verification.json`：文件校验值及测试记录。`quota.diff` 保存本次源码修改。

次数日志独立存储在 MCU Flash 的最后两个 1 KB 页（0x0801F800–0x0801FFFF）。应用可用范围为 0x0800C000–0x0801F7FF，升级文件不得超过 79872 字节。新启动程序会拒绝超限文件，HEX 镜像不包含次数页。使用外部工具“全片擦除”会清除次数；要保留次数请只擦除镜像覆盖的页面。旧启动程序可安装当前应用，但应更新新启动程序以保护后续升级。

## 保留的功能与验证

默认仍通过 `DAP_ONLINE_ENABLE=0` 关闭在线 CMSIS-DAP 仿真，保留 SWD/OPT 离线烧录、自动/手动模式、WinUSB 文件传输接口 1、CDC、硬件 SPI 及此前右键修复。正常中文保持统一的 32 像素细字，文件名和诊断信息为 16 像素，使用完整 320×240 屏幕；连接状态保留 CON/DIS。

应用关闭版、可选开启版及启动程序均已全量编译，0 错误、0 警告。最终交付应用为关闭版：RAM 16536/20480 字节，BIN 55264 字节；次数功能仅增加 RAM 24 字节。相对最初版本仍节省 RAM 3528 字节。

已执行实际编译的 Thumb 代码，验证 100 次成功后第 101 次拦截、999 次连续计数、失败退款、重启保留、50 个断电/存储故障场景、USB 设置/读取/忙碌拦截，以及自动/手动零额度入口。启动程序的超限文件拦截、当前应用及最大允许镜像写入均验证了两页次数记录不被覆盖。上位机协议、保存/读取、100/099/000 显示、3 种窗口大小与 OPT 配置回归检查通过。61 条提示、9 个屏幕、完整 31 字节文件名边界检查无裁切。
