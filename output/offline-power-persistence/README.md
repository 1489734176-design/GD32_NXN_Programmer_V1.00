# 芯片、固件与次数掉电恢复（2026-10-28）

重新上电恢复断电前已保存的芯片型号、所选固件、OPT开关与主固件校验值。剩余次数沿用原日志，不会在启动时重置或补回已扣次数。选择变化自动保存，相同选择不重复写Flash。

## 更新和使用

1. 用现有上位机上传 DAPlink.bin 到设备 /update/DAPlink.bin，重新上电完成更新；DAPlink.hex 是地址从 0x0800C000 开始的应用镜像。
2. 首次升级后重新导入一次芯片和目标固件，让新版本保存选择。后续断电再上电直接恢复这些选择；手动切换固件也自动保存。
3. algorithms/ 中为原配套算法，如设备已有同名算法无需再次上传。需要时传到 /download/firmware/。tools/ 沿用上一版上位机。
4. 通过 tools/run.bat 启动上位机。仓库内复用原Python3.12环境；单独使用需在tools中建立Python3.12 .venv并安装 intelhex pyusb PyQt5 libusb-package。

## 行为说明

- 成功烧录扣一次；普通失败退回一次；烧录中突然断电保留已经预扣的一次，重启不补回。
- 启动核对算法、固件及需要的OPT文件。有已保存主固件SUM32时重新计算并比较，缺失、空文件或校验不一致时清除可烧录选择，需重新导入或选择。
- 上传、删除、改名、开始导入或取消导入前先保存失效状态，避免上传中断后恢复旧固件。
- 保存失败禁止开始烧录或更改文件；重新导入/选择可重试保存。
- 选择日志位于内部Flash 0x0801F000～0x0801F7FF，次数日志仍为 0x0801F800～0x0801FFFF。本镜像不覆盖这两区。

## 文件和验证

DAPlink.bin/hex 为烧录器应用；modified-source.zip 为本次修改源码和Keil工程；verification/ 为构建、实际Thumb执行、断电故障注入和审查证据。标准FLM版、Bootloader无需更新。

完整Keil编译零错误/零警告，BIN与HEX一致；验证包含选择日志189个故障场景、启动恢复、USB变更保护及原有导入/次数/OPT/SUM32回归。尚未连接实物进行断电烧录测试。
