## RAM 与栈

内部 SRAM 按 `offline.map` 的 RW_IRAM1 计：`0x4DD8 = 19928B / 20480B`，剩余 552B 的静态链接空间。编译摘要 RW=844B、ZI=19228B 合计 20072B，其中还包含 `0x40006000` 固定 USB 外设区的 `0x90 = 144B`，该部分不占内部 SRAM；两个 execution region 已直接核对。名称缓存由 6 个增加到 12 个，新增 192B；没有 framebuffer 或按目录大小分配的数组。

真实 `offline.htm`：mode3 自身 80B，最大调用深度 732B；含 run_task 自身 80B 的列表路径约 812B。UI_NumberedItem 自身 128B、最大深度 364B；scan_firmware_page 自身 40B、最大深度 460B。全程序静态最大仍为原 mode4 路径 1956B，run_task 配置仍为 1024 个 32 位字（4096B），未发现新增栈峰值风险。

以上是链接器静态图及仿真证据；链接器原有 cycles/untraceable function pointers 注记仍存在，未声称测得实板任务栈高水位。完整应用、对齐和发布清单由 root 独立汇总。
