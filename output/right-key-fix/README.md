# 右键长按修复固件（2026-10-23）

适用于当前 GD32-HID/GD32-HID 加密版主程序，保留 ST7789 显示移植。

原因：按键扫描把长按右键发送成普通 key_right，模式切换却要求 key_l_right。现已恢复首次长按事件，并将后续连发分开。

- 离线下载待机页：右键按住约 0.5 秒，在自动和手动之间切换一次。
- 文件列表：左右键按住仍每约 0.1 秒连续翻页；松开长按不会额外触发短按。
- 中键短按、双击、长按的逻辑保留。

## 使用

DAPlink.bin 是烧录器本体的主程序升级包。通过设备文件传输将它替换到 0:/update/DAPlink.bin，再断电重启，由已有 Bootloader 升级。

若使用外部调试器直接烧写，DAPlink.hex 自带主程序地址 0x0800C000；BIN 起始地址也为 0x0800C000。已有 ST7789 Bootloader 无需修改。
