# NX Writer：固定预览与烧录说明

- [上位机原生窗口截图](opt-preview.png)：配置项滚到底部，OPT 数据和读保护状态仍然可见。只读预览来自本地配置，不是从目标芯片读回的值。
- [烧录器屏幕预览](device-preview.png)：由编译后的固件在仿真中绘制，非实机照片。镜像号上方仅显示已导入的说明，整行居中；未填或普通导入时留空。编号镜像沿用原有说明格式：最多 23 个可打印 ASCII 字符，空格、大小写和标点均保留。

本版只优化 A/B 通道连续写入和回读数据时的 SWDIO 引脚切换。ARM 模拟中，正常数据字传输所执行的指令约少 10%–11%；这不是整片烧录时间。擦除、读保护解锁、等待重试和校验流程保留原有行为。

默认使用[新版固件](DAPlink.bin)。另附[原速对照固件](stock-timing/DAPlink.bin)：两版界面相同，对照版使用本项目之前已验证的 SWD 时序，可用于对比速度或回退。

若比较烧录时间，请在新旧固件上使用同一块板、同一份目标程序、同样的 OPT 设置和通道数。从开始烧录到校验成功各测 5 次，比较中位数；不把电脑导入文件的时间算进去。双通道的结果单独记录，不与单通道混算。

上位机从项目的 [run.bat](../../GD32-HID/GD32-HID/tools/run.bat) 重新启动即可。更新烧录器时，将本目录的 `DAPlink.bin` 通过文件上传放入烧录器的 `/update/DAPlink.bin`，然后断电重启；不要把它作为目标芯片的程序导入。
