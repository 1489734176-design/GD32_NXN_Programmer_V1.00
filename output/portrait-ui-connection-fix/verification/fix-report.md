# 2%连接后卡死修复

用户实机症状：自动/手动接芯片后停在2%“正在连接芯片”，三个按键无响应；不接芯片时能正常报失败。

原因：竖屏缓存改变静态RAM布局，裸uint8_t算法工作区DATA_BUFFER从原版0x20002650移到0x200026B6。连接成功后mode4读取扩展算法头，实际LDRD指令访问0x200026EE，违反Cortex-M3强制字对齐要求。未开UsageFault时会升级为HardFault并进入既有异常死循环；5%提示尚未执行。

修复仅为bsp_gd25qxx.c的DATA_BUFFER定义增加__align(4)，并注明其共享算法头用途。修复后实际缓冲区0x200026B8，LDRD有效地址0x200026F0。原有布局、SWD时序和次数逻辑未改动。
