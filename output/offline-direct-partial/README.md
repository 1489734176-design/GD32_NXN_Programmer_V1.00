# 烧录直达与局部刷新版

日期：2026-10-26

本版删除设备上的一级模式菜单和文件传输页面。应用启动完成后直接显示自动烧录待机页（原图2）；USB供电、电池供电均相同。上位机在待机、手动选择、文件列表、烧录结果页面仍可连接、传文件和设置/读取次数。导入后保持连接，不需要返回在线模式。

## 刷新与按键

相同页面不再整屏擦除。温度、连接状态、电量、次数、文件名和状态文字各自更新；内容不变不写LCD，数字或文字改变只覆盖变化字符，变短内容只清掉多余尾部。文件列表移动光标仅更新旧/新高亮行；进度条只更新增减的条段和变化数字。仅真正切换布局时清屏一次。

屏幕仍为320×240，中文细字32像素，文件名/底部信息16像素。底部保留左侧按键提示，右侧CON/DIS、温度和电量。字库未改变，“开始烧录”与其它中文保持同一字体。

长按右键切换自动/手动；手动页左右选择算法/固件/开始，中键确认；文件列表中键确认，双击或长按中键返回烧录页。手动结果页按键返回选择页。烧录待机页长按中键关机（正在传文件时等待传输完成）。原一级菜单已删除，双击中键在选择页停留。

## 安装

- `DAPlink.bin`：应用升级文件。使用上位机上传到设备 `/update/DAPlink.bin`，然后断电重启；当前应用工作区Keil输出也已更新。
- `tools/run.bat`：新版上位机启动入口。工作区可直接复用已有Python3.12环境；独立复制时先创建tools/.venv并安装intelhex、pyusb、PyQt5、libusb-package。
- `DAPlink-Quota-full.hex`：启动程序+应用合并镜像，供外部烧录工具整机安装。推荐首次使用次数限制时安装受保护的启动程序。
- `Bootloader-Quota.hex/.bin`：启动程序镜像，地址0x08000000；本版也改为进度局刷。已有上一版受保护启动程序可继续安装当前应用；仅更换应用不会改变旧启动程序的更新进度显示。
- `DAPlink.hex`：独立应用，地址0x0800C000。
- `source-chinese-comments.zip`：40个此前/本次修改的源文件及工程，保留相对路径和原UTF-8/GBK编码。工作区源文件也已原位修改。新显示函数、USB/复位流程及转义中文显示字符串均有中文说明。

## USB和次数

USB文件指令不在中断里执行，统一交给主任务，避免FatFs与烧录互相干扰。文件打开、导入会话、请求/应答未完成时暂停自动开始；只有真正烧录时才阻拦文件/次数操作。手动烧录完成后仍显示结果，同时恢复USB文件和次数服务。USB复位/重插通过底层回调标记旧会话失效，文件关闭留在主任务。

导入失败/取消会关闭上传文件，并取消当前固件选择，防止自动烧录残缺文件；重新导入或选择完整文件后继续。导入会话覆盖固件和OPT两次上传，避免在两者之间开始烧录。

上位机可设置0–999次或不限，设备继续显示100→099→000；正常失败退款，掉电保留已预扣次数；额度不足拦截目标操作。文件导入和普通应用升级均不重置次数。在线仿真仍默认由DAP_ONLINE_ENABLE=0关闭，SWD/OPT、WinUSB接口1、CDC继续保留。

次数页为0x0801F800–0x0801FFFF；应用升级不得超过79872字节。HEX文件不包含次数页。若外部工具执行全片擦除会清除额度；保留额度应只擦镜像覆盖的页。
