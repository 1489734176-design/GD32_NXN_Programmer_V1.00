# 中文离线烧录器固件

日期：2026-10-23

默认关闭在线 CMSIS-DAP 仿真，保留离线 Flash/OPT 烧录、自动/手动模式、WinUSB 文件传输、CDC、ST7789 和此前右键修复。
设备使用完整 320×240 横屏像素坐标，取消原 128×64 居中画布。普通中文统一为图一对应的 32×32 像素细宋体：原生 16×16 点阵整数放大 2 倍，不加粗、不平滑。所有菜单（包括“开始烧录”）使用同一套字模。文件名和寄存器信息使用 16 像素高度；较长错误原因分行显示。自动页将文件名与中文标题分开，保留当前支持的完整文件名；文件选择每页五项。
连接状态按要求保留英文 CON/DIS。文件名、芯片名、SWD/OPT/SRAM/CDC/HID、错误编号及诊断寄存器名称保留；其他设备提示为中文。只保存用到的汉字。界面直接分块写入 LCD，不申请全屏显存；每次共享 SPI 事务最多 128 像素，保留此前 LCD/Flash 总线保护。

## 文件用途

- DAPlink.bin：应用升级文件，交给现有上位机上传到设备 `/update/DAPlink.bin` 后断电重启；只升级应用，不改变启动程序。
- DAPlink.hex：应用 HEX，地址从 0x0800C000 开始。
- Bootloader-Chinese.hex：中文启动更新界面，地址从 0x08000000 开始，需要外部烧录工具写入。
- Bootloader-Chinese.bin：Bootloader 原始镜像，写入地址 0x08000000；不要放到设备应用更新目录。
- DAPlink-Chinese-full.hex：中文 Bootloader 与应用合并镜像，供外部烧录工具整机写入。首次安装全部中文（包括启动/更新提示）可使用它。
- ui-preview.png：由实际字库和固件坐标渲染的八个界面预览。
- *-320x240.png：各页面的原始 320×240 像素预览。
- ui-translations.json：英文与中文对应表。
- manifest.json / verification.json：固件校验值与验证结果。

## 编译开关

`GD32-HID/GD32-HID/USER/APP/firmware_features.h` 中 `DAP_ONLINE_ENABLE=0` 为默认关闭；改成 1 或在 Keil C 预处理宏中定义 `DAP_ONLINE_ENABLE=1` 可恢复在线仿真。
同一宏会恢复 HID 通道、专用任务、事件组、软件定时器和原 8 KB RTOS 堆。关闭时堆为 6 KB。
共享底层 SWD、DAP_Setup 和扩展 OPT 算法保留。文件传输仍为 WinUSB 接口 1，无需修改现有上位机。

## 编译与检查

应用关闭版、应用开启版与 Bootloader 全量 Keil ARMCC 5.06 编译均为 0 错误、0 警告。交付应用最终为关闭版。
关闭版应用：Code 40696，RO-data 11792，RW-data 740，ZI-data 15772，RAM 16512/20480 字节，BIN 52816 字节。
修改前应用：RAM 20064 字节，BIN 60908 字节。新增中文字库与全屏布局后，仍净节省 RAM 3552 字节、Flash 镜像 8092 字节；相比上一版中文固件额外减少 RAM 984 字节。
Bootloader：RAM 15488/20480 字节，BIN 32716 字节，位于 48 KB 启动分区内。
已检查在线命令/缓冲区/任务符号移除、离线 SWD/OPT/文件传输/CDC 符号保留，USB 描述符与接口号、BIN/HEX 内容、向量和分区、字库及显示边界、源文件编码。
57 条静态应用提示、完整 31 字节文件名示例与寄存器诊断边界检查通过。实际字模对比确认图一菜单的 16×16 原始位图逐字节保持一致，统一放大到 32×32 显示。在线专用代码默认未链接，旧 OLED 显存和居中转换代码也已移除。
