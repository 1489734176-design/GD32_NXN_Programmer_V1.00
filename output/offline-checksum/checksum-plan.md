# SUM32 导入显示

用户已经选择 SUM32：最终主固件 BIN 每个字节累加，按无符号32位取模，显示8位大写十六进制。导入 HEX 时计算转换后 BIN（含填洞字节）；算法、OPT、地址与烧录尾页填充不计入。

1. 保存当前5个源文件快照（已完成），保留目前次数16px、源码编码与所有既有功能。
2. USB：扩展0x0C，flags bit1带期望LE32；成功回传[OK][SUM32 LE32]。SPI回读、长度/关闭/复位检查、期望比对均在提交前完成；复位和失败不提交旧选择。旧无期望格式继续接受。
3. PC：计算实际上传BIN、成功显示Checksum(SUM32)、新导入/失败清除旧值。保持连接和现有OPT/次数布局。
4. LCD：独立field13、16px，自动y166、手动y156、烧录/结果y224；仅在成功导入提交后有效。更换固件、改写/删除/重命名或取消后显示占位；独立栈缓冲，保护OPT路径D。
5. 先运行缺失功能失败测试；依文件分工并行实现，根代理顺序编译ON/OFF并跑原14脚本和新增3脚本。回归源码清单新增hash层，保留旧hash基线。
6. 独立全改动审查、修复重要问题、打包output/offline-checksum，核对镜像/源码/上位机hash，交付应用和启动入口。

接口：take_prepare_complete保留原3参数，新增prepared_checksum()在apply提交时读取；take_files_changed()先在主任务消费，再处理prepare提交。RAM只增加少量状态，流读用小栈缓存，不增加任务堆栈/全屏缓存。无Git，保留本轮快照和diff；不操作实物。
