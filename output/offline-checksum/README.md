# SUM32 校验显示版

日期：2026-10-26

程序导入成功后，上位机显示“Checksum(SUM32): 89ABCDEF”，LCD显示“Checksum: 89ABCDEF”，均为8位大写十六进制，前面补0。示例文件ASCII“123456789”的SUM32为000001DD。00000000也是有效校验值；横线--------表示尚未成功导入或原值已失效。

SUM32按最终主固件BIN的所有实际字节累加并取低32位。HEX导入按转换后BIN计算，地址空洞填充字节计入；烧录算法、OPT文件、地址以及目标Flash尾页额外填充不计入。上位机先计算期望值，设备回读SPI Flash文件并核对一致后才提交导入和显示，失败/不完整上传不能进入自动烧录。

LCD校验行使用16像素原字体，自动页位于剩余次数下方、手动页位于开始烧录上方，烧录和结果页位于最下面。复用字段13，只更新变化字符，不增加全屏刷新。当前次数16像素布局、320×240分辨率、细字库和CON/DIS保持现状。更换固件、写入/删除/改名、取消导入后清旧校验值，重新成功导入后显示新值。

## 使用

- 应用升级：使用上位机将DAPlink.bin上传到设备/update/DAPlink.bin，断电重启后使用新版上位机导入程序。
- 新版上位机：tools/run.bat。工作区启动时复用已有Python3.12环境；独立复制时安装intelhex、pyusb、PyQt5、libusb-package到tools/.venv。
- DAPlink.hex是地址0x0800C000的应用镜像；DAPlink-Quota-full.hex是启动程序+应用合并镜像，供整机外部烧录。
- 已安装上一版受保护启动程序的设备，只更新应用即可。Bootloader-Quota镜像保留原次数页保护和进度局刷。
- source-chinese-comments.zip包含40个此前及本次修改的源文件/工程，保留原UTF-8/GBK编码；工作区源文件已同步修改。新增显示、协议、校验和错误处理均有中文注释，checksum.diff对应本轮快照。

## 保留功能与验证

在线仿真仍默认DAP_ONLINE_ENABLE=0关闭，离线SWD/OPT、USB接口1、CDC、上位机连接、次数限制和局部刷新继续保留。导入过程不会扣烧录次数。USB复位及文件读/关闭/长度错误均撤销未确认会话；0x0C准备响应等待延长为30秒以适应回读，普通文件指令仍为5秒。

OFF应用、ON兼容版本和启动程序均0错误、0警告；交付为OFF应用。应用BIN 57384字节，RAM 17784/20480字节，比前一版仅增加24字节。ON RAM 20344/20480字节。

17个最终脚本通过，包括固定校验向量、HEX转换填洞、OPT排除、有效0、协议畸形包、不一致值、读取/短读/关闭错误、传输长度不足、USB复位、真实主任务提交、两端界面、三种上位机窗口尺寸、局刷逐像素一致、完整OPT流程、次数/掉电与启动程序保护。独立代码审查发现的失败CLOSE提交问题已补回归并修复。截图使用实际编译字库及绘制代码、Qt界面生成；截图值为演示值。未连接或烧录实物，硬件显示和实际目标烧录仍需实机确认。

次数页为0x0801F800–0x0801FFFF，所有交付HEX均不覆盖该区域。应用BIN最大79872字节；外部全片擦除会清除次数，应保留原次数页。
